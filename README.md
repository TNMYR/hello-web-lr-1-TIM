# Gamex

Статическая клиентская часть веб-приложения — каталог видеоигр.

## О проекте

**Gamex** — каталог видеоигр: пользователь может просматривать подборку игр,
знакомиться с жанром, платформой, годом выпуска и коротким описанием, а также
искать игры по названию и фильтровать их по жанру и платформе.

Проект предназначен для:

- игроков, которые хотят быстро найти игру под своё настроение;
- людей, которые собирают личную коллекцию «во что поиграть»;
- всех, кто интересуется видеоиграми и хочет видеть их в одном месте.

На этом этапе страница статическая: данные карточек хранятся прямо в HTML,
форма поиска и фильтрации не выполняет запросов. Интерактивность, сервер и
база данных появятся в следующих лабораторных работах.

Папка `front/` содержит клиентскую часть приложения. В дальнейшем рядом может
появиться папка `back/` для серверной части — тогда репозиторий будет содержать
два независимых проекта.

## Как открыть

1. Склонируйте репозиторий.
2. Откройте файл `front/index.html` в любом современном браузере
   (Chrome, Firefox, Edge, Safari).
3. Сборка, установка зависимостей и запуск сервера на этом этапе не требуются.

Проверить адаптивность можно в DevTools (F12 → иконка устройства),
переключаясь между ширинами 360, 768 и 1280 пикселей.

## Использованные технологии

- **HTML5** — разметка: `nav`, `main`, `footer`, `img`, ссылки.
- **CSS3** — оформление, палитра, состояния `:hover` и `:focus-visible`.
- **CSS Grid** — сетка карточек `.games-grid`
  (`repeat(auto-fill, minmax(...))`): карточки образуют двумерную сетку
  с ровными колонками и строками.
- **Flexbox** — навигация в шапке и `.content-row`: одномерные ряды
  элементов, которые должны равномерно распределяться по строке.

## Адаптивность

| Ширина | Поведение |
|---|---|
| 360 px | Одна колонка карточек, навигация переносится, форма в одну колонку |
| 768 px | Две колонки карточек, форма в две колонки |
| 1280 px | Три–четыре колонки карточек, форма в одну строку |

Горизонтальная прокрутка не появляется. Изображения не выходят за пределы
карточек: используется `object-fit: cover` и ограничение по ширине контейнера.

## Доступность

- Ссылки в навигации — настоящие `<a>` с `href` на существующие страницы
  в `front/pages/`.
- У изображений есть атрибут `alt`: содержательные — с описанием,
  декоративные — пустой.
- По странице можно пройти клавишей Tab.

## Про папку `js/`

Файл `front/js/main.js` пока не подключён к странице: по условиям первой
лабораторной JavaScript не требуется. Папка создана заранее, чтобы на следующем
этапе подключить интерактивность без перестройки структуры.

## Изображения

- `gamepad-svgrepo-com.svg`, `news-svgrepo-com.svg` — иконки с
  [SVGRepo](https://www.svgrepo.com/), лицензия — <указать лицензию>.
- Файлы хранятся локально в `front/icon/`, поэтому страница не ломается
  при отсутствии интернета.

## Что не реализовано на этом этапе

- Семантические теги `header`, `h1`, `article` — пока используются `div`
  с классами; будут добавлены при доработке разметки;
- форма поиска и фильтрации;
- JavaScript и интерактивность;
- серверная часть и база данных;
- работающий поиск;
- динамическая загрузка карточек.
